API Documentation

This page documents the app's JSON endpoints, including the experimental worded-problem flow. The app is intentionally lightweight and may change.

Back to practice Worded problems Integration solver Privacy policy

Core Endpoints

JSON
  • POST /api/solve - integrate an expression locally with SymPy. Body: {"expression": "x^2", "variable": "x"}.
  • GET /api/daily/<easy|medium|hard|newton> - fetch or create the daily integral for a level.

Experimental Worded Flow

beta
  • POST /api/word-problem - create a session-backed word problem. Returns prompt text, category, and the target LaTeX.
  • POST /api/word-problem/check - check a submitted answer against the current session problem. Body: {"answer": "..."}.
  • POST /api/word-problem/reveal - reveal the current solution in both raw SymPy and LaTeX forms.

The worded page at /worded is marked experimental on purpose. Prompt styles, categories, and wording may change without notice.

Notes

behavior
  • Responses are JSON unless a rate limit or validation error occurs.
  • Rate limits apply to the solver and the experimental worded-problem endpoints.
  • Worded problems are generated from the JSON bank in data/word_problems.json.
  • Theme preference, Q streak, daily streak, and points are stored in local browser storage only.
  • No account system exists, and no personal profile is required to practice.
