What We Store

summary
  • We do not require accounts, names, or email addresses to use the app.
  • Theme preference, Q streak, daily streak, and points are stored in browser local storage only.
  • Worded-problem context is held in your session cookie so answer checking works while you browse.

Server Processing

runtime only
  • Requests include standard web metadata (such as IP address and user agent) at the network layer.
  • Rate limiting uses short-lived in-memory keys to protect service stability.
  • Socket challenge state is kept in memory and expires automatically.
  • Daily integral content is cached by date and level, but this cache contains generated math data only, not user identity.

Third-Party Services

cdn usage
  • The UI loads Google Fonts, MathJax, and Socket.IO from CDNs.
  • Those providers may process technical request metadata under their own policies.

Your Controls

choices
  • You can clear local storage in your browser to reset theme, streaks, and points.
  • You can clear browser cookies to remove session-backed worded-problem context.
  • You can stop using the app at any time with no account deletion process required.
